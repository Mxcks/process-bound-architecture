# Communication in this repo

Communication is a production layer of PBA, not admin overhead.

- **Discuss a layer:** open an issue naming the layer file (e.g. `04-registration`). One layer per issue.
- **Propose a change:** a dated file in `docs/clarifications/` naming the source it clarifies. Never silently rewrite a source proposal.
- **Upload a policy/process library:** follow `how-to-register-a-policy-library.md`. Unregistered code does not run.
- **Report a test:** file it under the matching test case in `tests/test-cases/`, then link the experiment folder that ran it.
- **Dump an idea:** `ideas/inbox/` with `ideas/TEMPLATE.md`. Raw, dated, attributed. Filing happens later; capture comes first.
